# Game of Trees

Game of Trees (Got) is a version control system which prioritizes ease
of use and simplicity over flexibility.

## About Game of Trees

Got uses Git repositories to store versioned data. Git can be used
for any functionality which has not yet been implemented in Got.
It will always remain possible to work with both Got and Git on
the same repository.

Got relies on prior art and takes what makes Git's design great, leaves
out the parts that make Git hard for us to use, and invents new parts
for an end result which serves our needs.

Got is being developed on [OpenBSD](https://openbsd.org) by OpenBSD
developers and other contributors.
While Got's main target audience are OpenBSD developers, it is being used
for general version control tasks by users of OpenBSD and other Unix-like
operating systems.

See our [documentation](https://gameoftrees.org/manual.html) for details,
and follow the introductory
[tutorial](https://gameoftrees.org/eurobsdcon2026-got-tutorial.html) to
get started with our command line client.

## Hosting service

Using Game of Trees servers, we run an independent and transparently financed
Git hosting service called the [Game of Trees Hub](https://gothub.org).
Both community and professional hosting
[tiers](https://gothub.org/tiers.html) are available.
